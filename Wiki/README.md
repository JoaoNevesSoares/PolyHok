# PolyHok Wiki

This folder contains newcomer guides and DSL references for authoring GPU kernels in PolyHok.

Start here:
- `KernelAuthoringGuide.md`: practical kernel authoring guide and complete DSL form reference derived from the current codebase.

If you are new to the project, a good first step is to read the kernel guide and then browse `lib/poly_hok/ske.ex` for real kernels.
